# نجم كار

صفحة هبوط لنجم كار: مشاوير بمواعيد محددة مع كباتن، أسعار الرحلات، والحجز على واتساب.

- رقم الواتساب وقائمة الأسعار في آخر `index.html` (`WHATSAPP_NUMBER` و `FARES`).
- الصفحة ملف واحد، مفيهاش build. افتح `index.html` في المتصفح.
